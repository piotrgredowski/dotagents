Call the Skill tool twice, for "grilling" and "domain-modeling".

If the plan includes user-facing UI, the interview must also settle the visual decisions before it ends: product type, audience, mood or reference products, brand constraints, dark mode, density. Persist the settled decisions as a design spec (design-system MASTER.md via the ui-ux-pro-max skill with `--persist`), not only in conversation.
